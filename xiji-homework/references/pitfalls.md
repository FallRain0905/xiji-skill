# 判错排查清单

提交后出现「输出错误 / 格式错误 / 部分错误」时，先读详细评判（judgeDetails.jsp，展开全部差异对比），再按本清单从上往下对照。每修一处，先在本地用样例验证，再重提。

## 1. 格式错误（Whitespace 类）

- **提示符空格**：`input("How many numbers are there?")` 的期望可能是 `?` 后无空格；`Enter a number >>` 后无空格。期望输出里是几个空格就是几个。
- **行尾空格**：`print(x, end=" ")` 会在最后一行行尾留一个空格；期望无行尾空格时改用 `" ".join(...)` 后统一 print。
- **结尾换行**：有的题期望末尾无换行（多行 `print(x, end=" ")` 自然满足），有的期望有（普通 print 满足）。用 `repr()` 对比实际与期望的整段输出。
- **分隔符数量**：`sep="   "`（3 空格）vs `sep="\t"`（Tab）vs 默认单空格，以样例为准。

## 2. 类型与数值

- **整数结果误用 `.2f`**：期望 `36` 时输出 `36.00` 判错。只有小数题才用格式化小数。
- **eval 不认空格分隔**：`eval(input())` 只适合 `1,2,3`（逗号分隔，解析为元组）；空格分隔必须 `map(int, input().split())`。
- **input 未转换类型**：`input()` 返回 str，`s * 9` 是字符串重复（不报错但结果错），到 `/` 或 `+` 才崩。
- **浮点精度**：判题一般容忍 `%.2f` 级别；不要自作聪明引入 Decimal 或额外四舍五入。

## 3. 填空题（programFillGapList.jsp）缩进

- 平台可能把填空内容**按模板基础缩进整体再缩进一次**（`textwrap.indent` 行为）：内容只写相对缩进、首行顶格。
- 也可能**不加**（模板静态代码行尾是裸 `\n`）：内容必须自带缩进。
- 判断：看空位前 `code.cgcode` 的 textContent 行尾——`"\n    "` 会加 4 空格，`"\n"` 不加。
- 报错特征：`IndentationError: unindent does not match...`（内容带了不该带的缩进）或 `IndentationError: expected an indented block...`（内容缺缩进）。
- 总览页只显示「输出错误 0 分」，看不到真实报错——必须进详细评判。

## 4. 文件读写题

- **文件可能不存在**：评测可能不给输入文件，回退读 stdin：
  ```python
  try:
      f = open(name, "r", encoding="utf-8"); content = f.read(); f.close()
  except FileNotFoundError:
      import sys; content = sys.stdin.read()
  ```
- **输出到指定文件**：注意文件名精确匹配（`result.txt`、`jieguo.txt` 等），写模式 `"w"`。
- **CSV 引号包裹**：`csv.writer` 对含逗号/引号的字段自动加 `"..."`。期望输出无引号时用 `f.write()` 手写行。
- **编码**：输入按题面（通常 utf-8）；给 Excel 看的中文 CSV 用 `utf-8-sig`；判题比对用 `utf-8` 即可（BOM 会导致首行多 `\ufeff`，判题时注意）。

## 5. 语义类

- **字典重复键**：字面量重复键以后一次赋值为准，键顺序按首次出现。
- **排序平局顺序**：`sorted(items, key=lambda kv: -kv[1])` 是稳定排序，同次数保持首次出现顺序；字母序则再加 `kv[0]`。以期望输出为准。
- **集合输出**：集合打印顺序不确定；若题面声明「顺序不一致可忽略」则部分错误不算遗留。
- **标点串弯引号**：`biaodian` 类替换串复制时含 U+2018/2019/201C/201D，丢失会让 `China’s` 切不开。
- **素数判断漏 n<2**、**累乘初始值写成 0**、**哨兵循环先判 0 再判正负**——循环结构经典错。

## 6. 平台行为

- 提交后题页结果面板可能空白/不刷新——**总览页才是真相**。
- 同一作业老师可能中途改题（加题、改分值），总览页题目数变化时逐题核对。
- 作业过期后：编程/填空/单选入口关闭（标题不再是链接、答题页渲染为空），文件上传题无上传控件。过期即无法补交。
- 单选题总览只显示「已提交」不显示得分；编程/填空题显示得分与测试点明细。
